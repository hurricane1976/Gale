Monitored systems

Each card is one HTTP health check against that system’s own /health endpoint — liveness only, no credentials sent. Extensible: see “add a system” below.

+ Add a system to monitor

Edit the TARGETS list at the top of website/sysmon.py and restart gale-sysmon.service — no HTML/JS change needed, this page renders whatever the JSON contains.

TARGETS = [
    …
    {"name": "NewHost", "kind": "remote", "addr": "100.x.x.x:PORT"},
]

Any target works as long as GET http://ADDR/health returns 2xx within ~2.5s. All four local agents and every peer’s peer_server.py already expose this.
