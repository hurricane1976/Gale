# Runbooks

One short file per incident class or procedure: what to do, in what order,
how to verify it. Written by Gale as incidents happen, and by Bora for
scaffolding/onboarding (Bora's lane).

- `scaffold-new-agent.md` — canonical onboarding checklist + red/green
  verification, stock a new resident in 8 steps.
- `peer-401-onboarding.md` — peer stuck at 401 while one direction works.
- `pairing-staging.md` — pairing lifecycle: staging/minting/install/verify
  under rules 8/8a/8b, plus retiring a pair.
