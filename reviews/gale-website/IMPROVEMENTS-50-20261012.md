# Gale website — graphics enhancement queue #3 (2026-10-12)

Fifty new, code-grounded graphics suggestions. Every item names the file, selector, or function it builds on; nothing here repeats the shipped queues (`IMPROVEMENTS-50-20261009.md`, `IMPROVEMENTS-100-20261010.md` — all 150 items verified done/covered on 2026-10-10/12). Modern-CSS features already present and therefore **not** re-suggested: view transitions, scroll-driven `#progress`/`.reveal`, magnetic elements, `text-wrap: balance/pretty`, `::selection`, light theme, print styles, `forced-colors`, `prefers-reduced-transparency`, `@starting-style` dialogs, CSS anchor positioning, `field-sizing`, `interpolate-size` details, `scroll-state()` stuck indicator, `text-box` trim on vitals.

## A. Typography & numerals

1. **Slashed zero in mono counters.** `gale.css` loads JetBrains Mono but never sets `font-feature-settings`; uptime, p95, and SLO budget figures use the default dotted zero. Add `font-feature-settings: "zero" 1` (JetBrains Mono ships the `zero` feature) to `.vital-value`, `.mono-dim`, and SLO numerals so `0`/`O` are unambiguous at 0.74rem.
2. **Kill faux-bold during font load.** `fonts.css:5` notes Fraunces carries opsz+wght. If a subset loads late, browsers synthesize bold on `.vital-value`/h1. Set `font-synthesis-weight: none` on display faces so a late swap never re-renders headings with fake weight (pairs with the existing `document.fonts` readiness in shared.js).
3. **Wide-viewport type ramp.** The type scale stops at desktop breakpoints; on ≥2000px wide monitors the 14 routes render with mobile-ish density. Add a `@media (min-width: 2000px) { :root { font-size: 18px } }` and a 2200px step to 19px — every rem-based token scales, no per-page retune needed.
4. **Once-per-session hero cascade.** `gale.css:1837` runs `.js main { animation: page-in-g .55s }` on every route change (view transitions make it visible each nav). Stagger children — `h1`, `.sec-lede`, first `.stat-card` row — with `animation-delay: calc(var(--i) * 40ms)` gated on a `sessionStorage` "entered" flag so only the first paint of a session choreographs.
5. **Section eyebrow small caps.** Kicker/eyebrow labels above section heads (`.sec-lede`'s sibling) use manual uppercase + tracking. Normalize them with `font-variant-caps: all-small-caps; letter-spacing: .08em` in one `.eyebrow` utility so spacing is optically consistent at 0.8–1rem.
6. **Baseline trim for chart text.** `text-box: trim-both cap alphabetic` is applied to `.vital-value, .mc-name, .stat-card h3` only. Extend the same `@supports` block to metric axis tick labels and `.fleet-24h-name` values so numbers inside dense grids align to the same optical line as card headings.

## B. Color & theming

7. **OKLCH interpolation for state blends.** The 85 gradients in `gale.css` blend state colors in sRGB; `color-mix(in srgb, var(--warn) …)` produces muddy midpoints between `--ok #2fa874` and `--crit`. Switch state-bearing mixes (hb-card borders, meter fills, slo tracks) to `color-mix(in oklch, …)` for perceptually even warn→crit ramps.
8. **Per-page accent token.** All routes share `--flag`/`--gust` accents. Add `--page-accent` set per `<body data-page>` (weather: `--gust`, fleet: `--storm-purple`, metrics: `--flag`) consumed by `::selection`, link underline color (`gale.css:95`), `#progress`, and chip hover states, giving each route a subtle identity without new palettes.
9. **Time-of-day sky accent.** `weather.js` already computes `is_day`/sun phase for presets. Export one `--sky-accent` custom property (dawn amber → day teal → dusk violet) from the render pipeline and consume it in the weather hero gradient and `header.site` underline so page chrome follows the rendered sky.
10. **Theme-toggle crossfade.** Toggling `[data-theme=light]` (gale.css:1967+) snaps every token at once. Wrap the toggle in `document.startViewTransition(() => …)` in shared.js — the root crossfade pair (`::view-transition-old/new(root)`) already exists at gale.css:2161-2162, so the machinery is free; add a reduced-motion guard to keep the snap.
11. **Hour-tinted ambient blobs.** `.blob-a` (gale.css ~1100s keyframes) drifts on a fixed hue. Have `shared.js` set `--blob-hue` from local hour once per visit (`hue-rotate(calc(var(--blob-hue)) deg)` on `.blob`), so morning and late-night sessions feel different while staying inside the brand range.

## C. Surfaces & cards

12. **Trailing card glow via typed properties.** The `.card::after`/`.stat-card::after` hover glow reads `var(--mx)/var(--my)` written synchronously on every mousemove — it snaps. Register `@property --mx/--my { syntax: "<percentage>"; … }` and add `transition: --mx .18s ease-out, --my .18s ease-out` so the radial gradient lags the cursor with a weighted-trail feel; zero JS change.
13. **Conic border sweep on rule cards.** The mouse glow is radial; borders stay static. Add an angle-aware `conic-gradient(from var(--sweep), transparent 0 70%, color-mix(in srgb, var(--flag) 45%, transparent) 85%, transparent)` masked to the border-box on `.rule-card:hover` (rotate `--sweep` with a slow keyframe) — an angular counterpart to the existing spotlight.
14. **Press states for interactive cards.** Cards lift on hover (`translateY(-2px)` patterns throughout gale.css) but have no `:active` treatment. Add a shared `:active { transform: translateY(0) scale(.995); box-shadow: var(--card-shadow) }` rule for clickable cards/buttons so taps acknowledge immediately (skip on `hover:none` like mobile.css:47 already does).
15. **Radius and shadow scales.** `border-radius` appears 156×, `box-shadow` 54× with ad-hoc values (6/8/10/12/14/16/18/20px). Introduce `--r-1: 8px; --r-2: 12px; --r-3: 16px; --shadow-1..3` tokens and migrate component styles; visual output is unchanged today but future surfaces stop drifting.
16. **Paint containment on decorative layers.** `body::before` (4-stop sky), `body::after` flash wash, `.blob`, `.grain` are fixed full-viewport paint areas recomposited during scroll. Add `contain: strict`/`contain: paint` + `will-change` only where animated (the magnetic rule at gale.css:364 is the model) to cut composite cost on the 30fps tier.
17. **Sticky header condensation.** The `scroll-state(stuck: top)` pattern exists for `.topo-sticky-legend` (gale.css:2318) but `header.site` itself just stays full-height. Reuse the identical container-query idiom on the header: when stuck, collapse vertical padding 14px→8px and reveal the `stuck-line` hairline for continuity with the legend behavior.

## D. Data visualization & live feeds

18. **SLO bar draw-in + breach pulse.** `reliability.js` renders `.slo-threshold` SVG bars (track + actual rect) with no entrance or alarm motion. Draw `slo-actual` once via `stroke-dashoffset`/`scaleX` from 0 on load, and add a `pulse-in`-style soft border pulse on the tile when `budget_remaining_pct` is negative, both under the reduced-motion gate.
19. **Threshold-true meter gradients.** `status.js` meter bars carry `data-level` with warn=70/crit=90, but fills are flat colors. Give the fill a three-stop gradient whose stops land at exactly 70% and 90% of the track (`linear-gradient(90deg, var(--ok) 0 var(--warn-at), var(--warn) var(--warn-at) var(--crit-at), var(--crit) …)`) so color and threshold agree spatially, not just via label.
20. **Coverage-proof heatmap.** Reliability's coverage proof is text rows. Render the same per-day sample data as a 13-week × 7-day cell grid (GitHub-contribution style), each cell `color-mix(in oklch, var(--ok) calc(var(--n)/max) * 60%, var(--surface))`, with a `<title>` per cell — the data already exists client-side; this is a presentational transform.
21. **Legend↔series hover linking.** Multi-series charts (metrics comparisons, fleet lanes) don't connect their legend chips to the drawn series. On legend chip hover, dim all other series to 25% opacity via a `data-dim` class and thicken the target stroke — pure SVG class toggling, reduced-motion safe (no motion, just emphasis).
22. **Tabular ticks.** Chart axis labels aren't covered by the `tabular-nums` treatment used on cards; tick text jitters as values update. Apply `font-variant-numeric: tabular-nums` + item 6's text-box trim to all axis `<text>`/`.tick` labels.
23. **Desktop value chip on bar hover.** Metrics pins tooltips on touch (done in pass #2, item 34) and relies on `<title>` on desktop. Add a floating `.value-chip` positioned at the hovered bar's top edge (JS sets `left/top` from `getBoundingClientRect` in a rAF batch) so desktop gets the same immediacy without native tooltip lag.
24. **Edge fade masks on dense charts.** `mask-image` fades exist for `pulse-feed` (gale.css ~1100s). Reuse the same two-stop mask on wide table scrollers and the 24h sparkline rows so hard clip edges of scrolling data read as intentional.
25. **Fleet 24h column crosshair.** `.fleet-24h-*` grids render per-host rows of hour cells; hovering one cell highlights nothing shared. On hover, set `--col` on the grid and outline every cell whose `--i` matches (`[style*="--col"]` or JS class), giving a synchronized vertical sweep across hosts.
26. **Radar frame crossfade.** `weather.js:47` `showFrame()` swaps the RainViewer overlay layer per frame (900ms play delay) — frames hard-pop. Keep the previous tile layer one z-level below and tween its opacity to 0 over ~350ms before removal, plus a thin conic progress ring on `#wx-frame` reflecting autoplay position.
27. **Directional feed arrival.** `pulse-in` scales/fades new SSE rows centrally. For the narrow ops/lane columns add a `pulse-in-left` variant (12px translateX + fade) keyed by container class, so arrival direction matches where the row enters visually.

## E. 3D & canvas scenes

28. **Topology depth-of-field.** `topology3d.js` point shaders draw hard core + Gaussian halo with uniform brightness at all depths. Fade halo alpha by normalized view-space z (furthest quartile → 40% alpha) so the graph reads as a volume; a one-line clamp in the fragment shader, no CPU cost.
29. **Packet dashes on topology edges.** Links are static lines. Add a small per-edge phase uniform and animate a moving 20% dash window (`fract(t - phase)`) in an edge fragment shader — traffic visibly flows host→hub; keep it off on the 30fps tier where the frame-skip makes it stutter.
30. **Depth-aware DOM labels.** Labels are projected every frame with constant opacity (topology3d.js label pass). Scale label opacity/size by projected z (near = 1.0, far = 0.35, below threshold = `visibility: hidden`) to match perspective and cut label clutter in dense graphs.
31. **In-shader hover ring.** Node hover currently relies on DOM/CSS emphasis. Add a `uHovered` attribute and draw an expanding 1.5px ring in the point shader (radius eases in 150ms) so the highlight lives in the same perspective space as the node.
32. **Cluster halos.** Each host's node cloud floats without grounding. Add one large, very-low-alpha additive quad per host behind its nodes (position = cluster centroid, radius = spread) — depth cue that costs four sprites.
33. **Pulse-wall afterglow.** `pulsewall.js` clears fully each frame. Use a translucent full-screen quad (alpha ~0.22) as the clear pass so the ECG trace leaves a decaying trail — the classic persistence trick, gated off under REDUCED/30fps tier where trailing smears.
34. **Galaxy pointer parallax.** `galaxy.js` responds to drag but idles flat. When not dragging (and motion not paused), offset the star layer ±2% of viewport by pointer position with heavy damping — a cheap depth layer distinct from the orbit interaction.
35. **bars3d update spring.** `bars3d.js:178-199` eases hover/lift/flick but new poll data snaps bar heights. Interpolate `value` toward `target` with the same ~130ms-half-life exp ease used for flick glide so refreshes breathe instead of jumping.
36. **One resize/dpr pipeline.** Scenes implement resize/dprCap independently (topology3d.js has its own; others vary). Move a single `initCanvasResize(canvas, {dprCap})` into `shared-gl.js` and have topology/pulsewall/bars/galaxy consume it — one place to fix Safari DPR bugs or raise the cap.
37. **Quality-tier hysteresis.** The tier logic steps 60↔30fps on FPS samples but can oscillate near the boundary. Add a cooldown (e.g. 4s since last change) and require two consecutive out-of-band samples before stepping, so the HUD badge stops flickering on marginal devices.
38. **Static first frame for reduced motion.** `REDUCED3D`/reduced paths unmount to HTML fallbacks. Instead render exactly one frame (no loop) so reduced-motion users still see the real 3D composition as a still image, with the existing HTML view adjacent — better fidelity at zero animation cost.

## F. Motion choreography

39. **Synchronized skeleton phase.** Skeleton shimmers start per-element mount, so a polling page shows shimmering out of phase. Give all skeletons a shared negative `animation-delay: calc(-1 * var(--skew, 0s))` seeded once per page load so they pulse together (status.js `skeleton()` helper sets it once on `<body>`).
40. **Reduced-motion feed crossfade.** The reduced-motion path likely drops `pulse-in` entirely (instant swap). Add a motion-free variant — 180ms opacity-only crossfade — so feeds still communicate "new row" without scale/translate.
41. **Preset re-tint crossfade.** `weather.js` PRESETS switch palettes instantly. Fade the sky canvas + hero gradient over 400ms on preset change (two stacked canvases or CSS transition on the tint layer), with the reduced-motion snap preserved.
42. **Poll-cadence meter easing.** Status meters jump to new widths every 15s poll. Add `transition: width .9s var(--ease-out)` on the fill so values glide to their new level; the existing `tweenText` handles the numeral side — this makes the bar match the number.
43. **Tokenized focus ring.** Focus styles are hand-tuned per component (2px/3px, offsets 1/2px, `--gust`/`--flag-soft` mixed). Define `--focus-ring: 0 0 0 2px var(--bg), 0 0 0 4px var(--flag)` and swap all `:focus-visible` rules to it — consistent double-ring, guaranteed 3:1 against both surfaces, WCAG 2.4.13-friendly.
44. **Branded overscroll.** iOS rubber-band exposes `html` background (plain). Give `html` a deep-brand gradient (`--bg-deep → #0a1020`) and `overscroll-behavior: none` on the body scroller so bounce edges flash brand color instead of white/black.

## G. Cursor & micro-affordances

45. **Semantic cursors.** Everything interactive is `cursor: pointer` (gale.css:282 et al.). Add `cursor: crosshair` on chart canvases, `grab`/`grabbing` on the 3D surfaces (topology, pulse-wall, galaxy), and `text` on search fields — zero-cost wayfinding that matters on the dense dashboards.
46. **Live streaming caret.** `ollama.js:641-643` appends a literal `▍` for streaming. Style `.ol-cursor` as a 2px animated bar (step-blink at 1Hz, or soft pulse) with a reduced-motion static state, so generation activity is visible peripherally.
47. **Scoped scrollbar theming.** Global `scrollbar-color` exists (gale.css:61) but wide table regions inherit default thumbs in some engines. Set an explicit themed `::-webkit-scrollbar-thumb` (surface-2, hover → `--line-strong`) on `.table-scroll` regions only.
48. **404 lightning arc.** The 404 route uses stock page chrome. Add a single inline SVG bolt with `stroke-dasharray` draw-in on load (600ms, once) and a Fraunces "offline" display line — a memorable dead-end that reuses the storm motif; static under reduced motion.
49. **Reconnecting spinner on status pills.** Offline/reconnect states swap text instantly (shared.js banner logic). While a poll/SSE reconnect is in flight, show a 12px rotating dash arc in the status pill (`conic-gradient` mask or SVG `stroke-dashoffset` rotation), clearing on success or settling to the static offline chip.

## H. Kiosk & ambient

50. **Kiosk idle vignette.** `kiosk.js` runs indefinitely at full brightness. After 5 idle minutes, fade a radial vignette over the decorative layers (`body::before`, `.blob`, storm canvas opacity → 60%) and restore instantly on pointer/key activity; exempt content panels so telemetry stays readable, and skip entirely under reduced-motion.
